# Mechanism / paper

- **Source:** title, link, version, sections studied.
- **Status:** read / derived / implemented / checked.
- **Problem:** what does this improve, and why?
- **Math:** core equations, tensor shapes, assumptions.
- **Code:** implementation link and simplifications.
- **Check:** independent reference and one failure case.
- **Tradeoff:** quality, memory, computation; measurement conditions.
- **Evidence:** my result versus the authors' claim.
- **Recall:** explain the idea briefly without the paper.
- **Open question:** what remains unclear?
